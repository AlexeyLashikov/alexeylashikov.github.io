Git --- это система управления версиями, которая позволяет сохранять историю изменений проекта, возвращаться к предыдущим версиям и работать с ветками.

Основные возможности Git:

- сохранение истории изменений Git;
- совместная работа над проектом;
- удобное управление версиями файлов;
- возможность безопасно вносить изменения в проект.

При выполнении данного проекта Git использовался для хранения исходного кода сайта, фиксации изменений и публикации проекта в репозитории.
